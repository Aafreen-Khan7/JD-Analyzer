JD Analyzer and Skill Gap Detector
📌 Project Overview
JD Analyzer and Skill Gap Detector is an NLP-based Machine Learning project that analyzes Job Descriptions and identifies the skill gap between job requirements and candidate skills.
🚀 Features
Job Description Analysis
Skill Extraction
Candidate Skill Matching
Missing Skill Detection
Skill Match Percentage
ML-based Candidate Suitability Classification
TF-IDF Feature Extraction
Logistic Regression
Accuracy Evaluation
Confusion Matrix
Gradio Web Interface
🧠 Machine Learning
The project uses:
TF-IDF for text feature extraction
Logistic Regression for classification
NLP-based skill extraction
Skill matching for gap detection
🔄 Workflow
Job Description
→ Text Preprocessing
→ TF-IDF
→ Logistic Regression
→ Suitability Prediction
→ Skill Extraction
→ Skill Gap Detection
→ Final Recommendation
